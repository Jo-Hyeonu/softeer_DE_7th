- word cloud 동작 방법
    
    word cloud : 단어의 Frequency기반으로 크기를 조절하여 시각적으로 표현하는 기법
    
    - 단어의 가중치 산출
    - 충돌 없는 공간 배치 알고리즘
    
    ### Text Preprocessing
    
    - 토큰화 : 문장을 토근(개별 단어 단위)로 쪼갠다
    - 불용어 제거 : 의미 분석에 기여하지 않는 단어 (’the’ , ‘is’, ‘a’ .. ) 제거
    - 정규화 : 대소문자 통일(Lowercasing), 표제어 추출(Lemmatization) 하여 같은 의미의 단어 합치기 (eg. ‘running’, ‘ran’ → (‘run’, 2) )
    
    ### Weight Calculation
    
    - 빈도 계산 : 단어 등장 횟수(f) 카운팅
    - 크기 매핑 : 빈도에 정비례하게 되면 빈도 차이 클 때 가독성이 떨어짐 → 로그, 제곱근 스케일 사용하여 조절. (eg. log(f), sqrt(f))
    
    ### Layout Algorithm
    
    - 주로 나선형 배치 방식 사용
    - 정렬 → (중심배치 및 확산 → 충돌감지)
